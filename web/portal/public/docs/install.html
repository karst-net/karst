Install and verify Karst

Download the installer for your platform from the Karst portal. Before installing, compute its SHA-256 checksum and compare it character-for-character with the checksum shown beside that release.

Windows

Get-FileHash karst-windows-amd64.msi -Algorithm SHA256

macOS and Linux

sha256sum INSTALLER

Do not install an artifact whose checksum differs. Download it again from the portal; if it still differs, contact your administrator.
