Karst quickstart

Open the Karst administration console and complete First-run setup. You need the public HTTPS URL of your coordination server.

  1. Configure the coordination server and identity provider, and open the console or /portal/ over trusted HTTPS. Sign in as the user who will own the device.
  2. Install the Karst Linux client package on the device. In the portal, confirm that installation is complete and select Create enrollment bundle. Download the bundle; it contains the server pins and a one-device credential valid for fifteen minutes.
  3. In the download directory run chmod 600 karst-enrollment.toml, then sudo karst enroll --bundle karst-enrollment.toml. The client generates its private keys locally, authenticates the pinned server, and writes /etc/karst/karstd.toml without retaining the enrollment credential.
  4. After successful enrollment delete the bundle, then run sudo systemctl enable --now karstd and sudo karst status. If enrollment fails, retry with the same device state. Existing configurations are never overwritten.
  5. Confirm the device in Machines. If Bedrock is enforcing, complete the offline signing ceremony; network access also requires an ACL. Enrollment does not automatically grant access to every device.

If the node is absent or stale, check its service logs and confirm its coordination-server URL before generating another key. Never paste a one-time key into a ticket, chat, or shell history you do not control.
