Karst quickstart

Open the Karst administration console and complete First-run setup. You need the public HTTPS URL of your coordination server.

  1. In the administrative console, open Machines → Add machine. Enter a device label, select its access groups, and create an invitation. Give it privately to the recipient. It expires in 24 hours and authorizes one device.
  2. Install the Karst Linux client package on the device and open Karst Setup from the applications menu.
  3. Paste the invitation, select Connect, and approve the operating-system permission prompt. No recipient account, portal login, or identity-provider interaction is required.
  4. Setup verifies the server, generates local keys, registers the device, and starts its service automatically. If it reports pending Bedrock approval, ask the administrator to approve the device. If setup fails, choose Retry; saved registration does not require another invitation.
  5. Confirm the device in Machines. If Bedrock is enforcing, complete the offline signing ceremony; network access also requires an ACL. Enrollment does not automatically grant access to every device.

If setup cannot finish, use its status message and Retry action. A registered device does not need another invitation to retry its connection. Administrators can revoke unused invitations and review device status in the console.
