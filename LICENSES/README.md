Canonical license texts, named by SPDX identifier.

**Fetched, never transcribed by hand** — `just licenses` (or
`scripts/fetch-licenses.sh`) pulls them from spdx.org and gnu.org. A license
text retyped or reflowed is no longer the license it claims to be, so a diff
here should only ever appear when upstream changes one.

They are committed rather than fetched on demand. That is a change from the
original arrangement, which gitignored them: it left a public repository
showing no license at all, and it broke the REUSE layout these filenames exist
to satisfy.

See ../LICENSE for which license applies where, and LICENSING.md for why.
